## ✨ 它能做什么

群友说一句话，Bot 用它回你，**声音是动森村民那种叽里咕噜的腔调**。

不是 TTS，不是变声器——是从 407 个真人录制的普通话音节里挑出来拼的，
和《动物森友会》本体用的是同一套方法。

```
用户：今天好热啊
Bot：  🔊（动森腔）「就是啊，热得我都想跳进河里了」
```

## 🎛 全部参数，滑块搞定

装好后打开 WebUI → 插件 → 动森语音 → 配置，九个参数全是可视化控件：

| 参数 | 控件 | 默认 |
|---|---|---|
| 启用自动语音回复 | 开关 | 关 |
| **自动语音触发概率** | 滑块 1-100 | **100** |
| 音高 | 滑块 300-700 | 400 |
| 语速 | 滑块 5-25 | 13 |
| 最大字数 | 滑块 10-300 | 150 |
| 最小字数 | 滑块 1-20 | 2 |
| 允许会话内覆盖 | 开关 | 开 |
| 同时发送文字 | 开关 | 关 |
| 临时音频保留 | 滑块 1-120 分 | 10 |

### 概率语音

把概率设成 **30**，就是十条回复里大约三条发语音、七条保持文字。

既有点缀效果，又不会让不方便听语音的人难受。

## 🎵 音色参数怎么调

### 音高

| 数值 | 听感 |
|---|---|
| 364 | 音库原音，最自然 |
| **400** | 动森实际音域（默认） |
| 480 | 偏尖，更像小动物 |
| 560+ | 花栗鼠 |

音高越高，语音越短——这是物理规律，不是 bug。

### 语速

| 数值 | 听感 |
|---|---|
| 10 | 慢，每个字都听得清 |
| **13** | 接近原版（默认） |
| 18 | 叽里咕噜 |
| 22+ | 很快，可能糊 |

## 🔬 它是怎么发声的

```
文本
 └→ 汉字查表得 (音节, 声调)
     └→ 从 407 个音节单元里挑对应音节
         └→ 按声调算出播放速率曲线
             └→ 变速播放（音高随之改变）
                 └→ 按标点插入停顿
```

核心洞察：**音高只靠播放速率改变**，所以越高越短。
声调幅度被压到 0.35 倍——这就是动森语听着"平"却不像念经的原因。

音色 EQ 按《动物森友会》中文对话实测：2/3 次谐波压到基频下 11-13 / 16-20 dB，4 kHz 以上能量低于 1.5%。

## 🐛 已知限制

- **英文按字母念**：`hello` 读作 h-e-l-l-o，不是单词读音（音库只有普通话音节）
- **多音字取最常见读音**，不结合上下文
- **不支持日文/韩文**（参考实现支持 11 种语言）
- **音色固定**：换音色需要重建音库，不是改配置能解决的
